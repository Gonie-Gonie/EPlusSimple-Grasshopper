# Upstream provenance

This directory pins and maps the historical Python source used to validate the
Gonie-Gonie InvisibleDragon and SimpleDragon ports. Exact repository URLs,
module keys, paths, and symbols from that source remain unchanged so hashes and
compatibility mappings are auditable.

Accordingly, `snu-bslab/EPlusSimple`, `src/idragon`, and `src/epsimple` may
appear in files in this directory only as upstream provenance. They are not
project ownership, package, assembly, namespace, schema, or artifact names for
the public products intended for this repository.
